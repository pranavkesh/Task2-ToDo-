# To-Do List Application

## Task 2 - Python Developer Internship

A simple console-based To-Do List application developed using Python.

## Features

- View tasks
- Add new tasks
- Remove tasks
- Store tasks in a text file
- Tasks remain saved after closing the program

## Technologies Used

- Python
- File Handling
- Lists
- String Manipulation

## How to Run

Run the following command:

python todo.py
